Tag Description
"hr" Used to create horizontal lines. No closing tag. Add attributes width, color, and size
"tr" and "td" "tr" tag creates a table row. The indented "td" tag creates a column within that row. Ex: |tr||td|"Price"|/td||/tr|
"table" Creates a simple table that must be used with closing. Attributes: border, cellspacing, bgcolor, align, cellpadding, width, and height.
"ul" and "ol" unordered and ordered lists created with these tags You can use "li" to create text in these lists. Nested lists are created by putting a 'ol' into a 'ul'.
