How to use VIM

by a VIM professional

  1. Make sure that the Terminal is downloaded on your PC
  2. Open the Terminal and use cd to locat to the folder where you want your code
  3. Once you in the correct folder type vim name-of-script.htmland hit Enter
  4. To navigate the VIM you can use h,j,k,l or the arrow keys
  5. Now you know the basics of VIM.
